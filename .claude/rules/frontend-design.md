# 前端视觉设计规范

前端页面/组件的视觉设计必须遵循以下规则。

## 美学方向

- 编码前必须确定清晰的美学方向（极简 / 极繁 / 复古未来 / 有机自然等）
- 禁止生成面目模糊的 "AI 风格" 界面
- 实现复杂度匹配美学愿景：极繁要丰富效果，极简要精准克制

## 字体

- 禁止使用 Arial、Inter、Roboto、Space Grotesk、System UI 等常见字体
- 必须搭配一款特色展示字体 + 一款精致正文字体

## 色彩

- 色彩系统必须强烈统一：主导色 + 锐利点缀色
- 禁止平淡均匀的调色板
- 使用 CSS 变量管理色值，保持一致性
- 禁止使用紫色渐变白底的陈词滥调配色

## 动效

- 动效集中在高光时刻：页面加载的交错入场动画
- 优先 CSS-only 动效（`animation-delay` 实现交错）
- React 中可用 Motion/Framer Motion 库

## 布局

- 打破常规布局：不对称、重叠、对角线、打破网格
- 善用负空间，控制视觉密度
- 避免可预测的排版模式

## 背景

- 禁止默认纯色填充
- 使用渐变网格、噪点纹理、几何图案、分层透明度
- 戏剧性阴影、装饰性边框营造深度

## 独特性

- 每个设计独一无二，跨模块刻意变化字体/配色/布局
- 禁止跨项目收敛到相同选择
